# Harf Çarkı · Letter Wheel

Harflerden bütün kelimeleri türet!

Harflere sırayla dokunarak kelime kur ve gönder. Üstteki boş kutular bulman gereken kelimeleri gösterir. Fazladan bulduğun kelimeler de puan getirir.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
